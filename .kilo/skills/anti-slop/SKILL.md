# Anti-Slop: Universal AI Quality Defense

LLMs naturally gravitate toward generic, safe, and over-represented clichés: purple/blue gradients, centered heroes with emojis, robotic docstrings apologizing for changes, and corporate marketing filler. Anti-Slop enforces human craft, aesthetic intentionality, and engineering dignity.

## The Three-Tier Validation Framework

1. **Tier 1: Hard Gates (Absolute Bans)**:
   - No default purple/blue gradients or unbranded radial glowing orbs.
   - No robotic comment headers (`// ==================== HELPER FUNCTIONS ====================`).
   - No AI buzzword salad ("delve", "testament", "tapestry", "seamlessly", "revolutionize").
   - No single-word colored accents in headlines.

2. **Tier 2: Purpose Gates (Justify or Remove)**:
   - Modals and popups require explicit user-initiated intent.
   - Extra decorative borders, glassmorphism, or floating badges require functional justification.

3. **Tier 3: Quality Locks (Consistency & Liveliness)**:
   - **Energy Dial**: Match motion and visual weight to the brand identity.
   - **Rhythm Dial**: Vary section heights, layouts, and data densities. Never repeat the same 3-card grid on consecutive sections.
   - **Contrast & Legibility**: Strict WCAG compliance; dark mode must not be muddy `#111` with unreadable gray text.

## The 4-Block Delivery Gate

Before completing any UI or code generation task, run through the Delivery Gate:

1. **Block A (Visual Grounding)**: Cites brand tokens and palette origin. No unbranded gradient defaults.
2. **Block B (Code Cleanliness)**: Zero redundant comments explaining obvious language syntax. Clean types.
3. **Block C (Content Authenticity)**: Real subject-matter copy. No lorem-ipsum or generic placeholder promises.
4. **Block D (Verification Pass)**: Explicitly passes accessibility and layout checks.
